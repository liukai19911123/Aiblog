> 一个好的个人网站，不应该让维护它这件事比写作本身更费力。

## 为什么还要做个人博客

社交平台让发布变得容易，但也让内容被算法、时间线和平台规则所塑造。个人博客的价值不在于“更专业”，而在于你拥有内容的组织方式、呈现方式和保存方式。

我希望这个空间有三个特点：

- 打开得足够快，不用等待复杂的应用加载；
- 写作足够简单，一个 Markdown 文件就是一篇文章；
- 结构足够稳定，几年以后依然能轻松迁移。

## 最小而完整的内容系统

这个网站没有数据库，也没有后台。文章正文保存在 `posts/` 目录，标题、日期和标签则登记在 `js/config.js` 中。

```js
{
  slug: 'my-new-post',
  title: '我的新文章',
  date: '2026-08-18',
  category: '创作手记',
  tags: ['写作'],
  excerpt: '一段简短摘要',
  file: 'posts/my-new-post.md',
  published: true
}
```

这种方式不是功能最多的，却足够透明：没有隐藏的状态，没有无法导出的内容，也没有必须持续维护的服务端。

## 设计应该退后一步

个人博客的主角始终是文字。视觉设计需要建立辨识度，但不应该争夺注意力。因此我选择了接近纸张的背景、带有人文感的标题字体，以及只在关键位置出现的珊瑚橙。

留白不是空，它负责组织节奏。克制也不是单调，它让读者更容易知道下一眼应该看哪里。

## 接下来

网站只是容器。真正让它生长的，仍然是持续写下具体、诚实、有用的内容。比起一次性把所有功能做完，我更愿意让它随着写作习惯慢慢演化。
